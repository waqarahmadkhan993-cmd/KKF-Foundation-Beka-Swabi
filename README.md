# KKF-Foundation-Beka-Swabi
Khadim-e-Khalq Foundation (KKF) is a non-political welfare organization based in Beka, Swabi, dedicated to serving humanity through food assistance, educational scholarships, medical aid, and emergency support. Our mission is to help underprivileged families and build a stronger, caring community.  Slogan: Serve Humanity, Worship Allah.
